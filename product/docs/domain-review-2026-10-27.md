# 도메인 회의 반영 — 2026-10-27

## 확정 범위

1. 실내 환경 센서는 **온도·습도만** 설치합니다. 홈 카드, 환경 그래프, 새 모의 센서 입력을 두 항목으로 제한합니다. 미설치 밝기·수위 때문에 누락 경고를 발생시키지 않습니다. 과거 데이터/연구 호환용 optional API 필드는 유지하지만 제품 센서 범위로 안내하지 않습니다.
2. 기록은 **월간 캘린더 기본 / 목록 전환**을 제공합니다. 기록한 날짜를 기준으로 날짜별 건수와 활동 종류를 표시하고, 날짜 선택·이전/다음 달·이번 달·활동 필터·내용 검색·최신순/오래된 순/활동 종류순 정렬을 제공합니다. 최근 100건 대상임을 화면에 명시합니다. 달력 날짜는 브라우저의 현지 시각 기준이며, 과거 활동 날짜 수정/소급 입력은 이번 범위가 아닙니다. 기존 저장 기록을 유지합니다.
3. **시뮬레이션 탭과 홈 빛 분석 카드를 제거**합니다. 연구 엔진, 기존 결과 파일 및 API는 삭제하지 않습니다.
4. **카메라 관찰 → 잎 분할 → 관리 후보 제안 → 사용자 확인**을 후속 개발 방향으로 둡니다. 현 UI에는 준비 중 상태와 한계를 표시합니다.

## 카메라 후속 개발 순서 및 완료 기준

- 촬영: 카메라/영상 주기·식물 식별·촬영 시각 계약을 정하고 이미지/영상과 식물 연결이 확인될 것.
- 잎 구분: 잎별 마스크와 식별자, 불확실한 영역을 표시하고 전문가 검토 데이터로 평가할 것.
- 제안 기준: 제거 대상의 농학적 기준과 제외 조건을 전문가와 정의할 것. 세그멘테이션 결과만으로 불필요한 잎을 단정하지 않을 것.
- 검토 화면: 근거 이미지, 대상 잎 표시, 제안 이유, 불확실성, 사용자 확인/보류/수행 기록을 함께 제공할 것.
- 파일럿: 잘못된 제거 제안과 미탐을 검토하고 기준을 승인한 후 제한된 사용자 대상 적용할 것. 자동 가지치기 제어는 별도 범위.

현재 모델 기반 질병 진단·가지치기 추천·영상 분석은 구현하지 않았습니다. 공개 Pages에서는 여전히 모의 데이터만 표시하고 기록은 해당 브라우저에만 저장합니다.
