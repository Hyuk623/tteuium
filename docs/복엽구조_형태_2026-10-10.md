## 1. 확정된 결정 (user_stated)

1. **복엽을 두 타입으로 나눈다: 평평한 타입 / 구부러진 타입.**
2. **기준은 엽축(복엽 중심축)의 휨.** 소엽 잎몸의 휨·말림은 이 분류에 넣지 않고 **따로 정한다**(미정).
3. CLI용 프롬프트는 MD 파일 형식으로 정리한다.

## 2. 타입별 관찰 (측면 사진 기준)

### 평평한 타입 (예시 3장)
- 엽축이 줄기에서 나와 거의 수평으로 곧게 뻗음. 아치·활 모양 없음.
- **끝부분 처짐은 허용**: 2장에서 마지막 소엽 근처만 아래로 꺾임 → 끝 처짐만으로는 구부러진 타입이 아님.
- 한 장은 소엽 잎몸 말림이 심했지만, 소엽 휨은 별도 기준이라 분류에 반영하지 않음.

### 구부러진 타입 (예시 4장)
- 엽축 **중간부터** 휘어 복엽 뒤쪽 절반이 통째로 아래로 내려감.
- 끝 방향이 기부 방향 대비 대략 90° 이상 꺾임 → 수직으로 매달리거나 줄기 쪽으로 되돌아오는 갈고리형.
- 형태 두 가지 확인:
  - **꺾임형**: 중간에서 꺾여 내려감 (3장)
  - **아치형**: 기부에서 위로 솟았다가 전체가 둥근 아치로 넘어감 (1장, 사용자가 "휜 복엽에 추가"로 지정)
- 상방 사진에서는 뒤쪽 절반이 서 있어 **투영 면적이 크게 줄어듦** → 상방 추적·면적 추정에서 따로 다뤄야 함.

### 평평 vs 구부러진 차이 요약
| | 평평한 타입 | 구부러진 타입 |
|---|---|---|
| 휘는 위치 | 끝(마지막 소엽 근처)만 | 엽축 중간부터 |
| 끝 방향 꺾임 | 작음 | 기부 방향 대비 ~90° 이상 |
| 상방 투영 면적 | 실제와 가까움 | 크게 과소 |

## 3. 판정 방법 — 엽축 기부 방향 기준 꺾임각 θ (제안 상태, 미확정)

**수평선 기준 금지.** 아치형처럼 기부가 위로 서 있으면 수평 기준으로는 "약간 아래"로만 보여 오분류됨. 반드시 엽축 자신의 기부 방향을 기준으로 잰다.

1. 엽축에 점 4개 (복엽당 ~10초)
   - P0: 엽축 기부 (줄기 부착점)
   - P1: 첫 소엽쌍 부착점
   - P2: 엽축 중간
   - P3: **마지막 소엽쌍 부착점** (정소엽 끝 아님 → 평평한 타입의 끝 처짐을 자동 제외)
2. 기부 방향 = P0→P1, 끝쪽 방향 = P2→P3, θ = 두 방향 사이 각 (0° 일직선, 180° 완전히 되돌아옴)
3. 가안 경계: θ < 45° 평평 / θ ≥ 90° 구부러짐 / 45–90° **중간형으로 표시해 두고 나중에 판단**
   - 눈대중: 평평 예시 3장 ≈ 10–30°, 구부러진 예시 4장 ≥ 100° → 간격 넓음
   - **경계값은 예시 7장을 이 방법으로 실측한 뒤 확정** (사용자 결정 사항)
4. 측면 사진은 투영이라 각도가 틀어질 수 있음 → 측면 4장 중 **엽축이 가장 길게 보이는 뷰**에서 잰다.
5. 보조 지표(선택): P0→P3 직선거리 ÷ 경로 길이(P0→P1→P2→P3). 아치형에서 작아짐 → θ가 애매할 때 근거.

## 4. 복엽 1개 해체 측정 (기준 표본)

캘리퍼 + 커팅 매트(15×10 cm, 1 cm 격자). 사용자 확인 완료: 배치가 실제 쌍 위치 그대로, 전체 길이 값 맞음.
**실측값은 전체 길이 하나뿐**, 나머지는 사진 눈금 어림(±2 mm).

### 구조 (기부 → 끝)
| 위치 | 구성 | 최대 길이(어림) |
|---|---|---|
| 엽병+엽축 | 중심축, 떨어진 소엽 마디 흔적 | ~3.3 cm |
| 1쌍 (기부) | 좌·우 소엽 | ~2.0 / 1.8 cm |
| 2쌍 (가운데) | 좌(기부에 소소엽 1개)·우 | ~2.4 / 2.6 cm ← 최대 |
| 3쌍 (위) | 좌 녹색 · 우 갈변·말림 | ~2.3 / 1.7 cm (우는 손상으로 수축) |
| 사이 소엽 | 엽축 위쪽에 붙은 작고 둥근 1쌍 | ~1.0 cm |
| 정소엽 | 소엽병 + 기부의 작은 소엽 | ~2.3 cm |
| **전체** | 엽병 기부 ~ 정소엽 끝 | **50.71 mm (캘리퍼 실측)** |

→ 1차 소엽 3쌍 + 정소엽 1 + 사이 소엽 1쌍 + 소소엽 ≥1.

### 크기 비율 (최대 소엽 2.6 cm = 1.00)
- 2쌍(가운데) 0.92–1.00 (최대)
- 정소엽 ~0.9
- 3쌍(위) ~0.9 (손상 안 된 쪽)
- 1쌍(기부) 0.70–0.77
- 사이 소엽 ~0.4
- 최대 소엽 / 복엽 전체 길이 ≈ 0.5
- 형태: **가운데 쌍 최대, 기부 쪽 작음**
- 소엽 장폭비(3쌍 좌) ≈ 2.3 × 1.5 cm = 1.5 → 기존 실측 범위 1.4–1.7 안

## 5. 프로젝트 내 연결

- **P(말림) 셀**: 남은 최대 편차(aspect 0.485 vs 0.555)와 직결. 엽축 휨 타입이 생성기의 휨 분포 근거가 됨.
- **D.1 평면 잎 가정**: 구부러진 타입은 이 가정이 깨지는 쪽.
- **diaf024**: curl down −4.9 % (95주/m² dynamic), curl up은 static/dynamic 부호 반전 → 휨 방향도 기록 가치. 단, static 수광 이득으로 휨을 정당화하는 것은 금지(기존 규칙).
- **phynotype2 (상방 잎 추적)**: 구부러진 타입은 투영 면적 과소 → 타입 라벨을 트랙 속성으로.
- **F.3 (소소엽 확장)**: 사이 소엽·소소엽이 실물에 존재 — Butturini가 뺀 부분의 실측 근거.
- **F.7 분류기 / C3 소엽 수 시트 / 파괴 세션 클래스별 윤곽**: 타입 칼럼 추가 후보.

## 6. 열린 항목

1. **해체한 이 복엽이 떼기 전 평평/구부러진 타입 중 무엇이었는지** — 미확인. 타입별 크기 비율 비교에 필요.
2. θ 경계값 확정 (예시 7장 실측 후).
3. 소엽 잎몸 휨·말림 기준 (별도로 정할 예정).
4. 갈변 가장자리 면적 처리: 녹색 부분만 vs 원래 윤곽 (정소엽, 3쌍 우, 2쌍 우 끝에 갈변).
5. 사진 원본 저장 위치 — 이번 세션 사진 9장(평평 3, 구부러진 4, 해체 2)을 `data/records/` 아래 폴더로 옮기고 파일명 ↔ 타입 대응표 작성.
6. 소엽별 길이·폭 실측(캘리퍼)으로 §4 어림값 대체 — 파괴 세션에서 같이 하면 비용 거의 0.
