## 1. 확정 사양

### 1.1 재배

| 항목 | 값 |
|---|---|
| 품종 | 초소형 왜성 방울토마토 (지주 불필요) |
| 화분 | 5 × 5 × 7 cm | 미정(사용자수정*)
| 배지 | 질석(vermiculite) |
| 관수 | 상시저면 |

구현상 함의: 질석 표면은 밝고 균질 → 배경/배지 분리가 쉽다. 단 **판(ChArUco)도 밝은 영역이 있으므로
마스킹은 색이 아니라 "판 평면 + 판 실측 범위" 기하 조건으로 제거한다.** 색 임계값으로 배지를 지우려 하지 말 것.

### 1.2 기준판 — 7×7 확정( 아니다, 5x7로 확정이다 )

| 항목 | 값 |
|---|---|
| 변형 ID | **`charuco_7x7_190mm`** |
| 종류 | ChArUco (체커보드 + ArUco 마커) |
| 사전 | `DICT_4X4_50`, `legacy_pattern: false` |
| 칸 배열 | **7 × 7** |
| 칸 크기 | **190/7 = 27.142857142857142 mm** |
| 마커 크기 | **19.904761904761905 mm** |
| 판 전체 | **190 × 190 mm** |
| 용지 | A4 세로, 100% 실제 크기 |
| 내부 코너 | **36개** |
| 마커 | **24개** (ID 0~23) |
| 재질 | 무광 용지 → 평평한 판에 기포 없이 부착 |
| 설치 | 회전판 위에 고정 — 식물과 함께 회전 |

인쇄 파일: `build/charuco_board_7x7_190mm_A4.pdf`

**칸 크기는 자로 검수하지 않는다.** 27.142857…은 잴 수 없는 값이다.
검수는 **판 전체 190 mm**와 여백의 **100 mm 자 막대** 두 가지로 한다.

#### 예비 판 — 5×5

`build/charuco_board_5x5_190mm_A4.pdf` (5×5, 칸 38 mm, 마커 12개, 코너 16개, 판 190×190 mm)를
예비로 보관한다. **운영 판이 아니다.**

> **두 판의 마커 ID가 겹친다.** 사진만 보고는 어느 판인지 구분할 수 없다.
> 세션 매니페스트의 `board_variant_id`만이 판을 식별한다. 이 값이 틀리면
> 검출은 정상으로 보이면서 모든 치수가 틀린다 — 파이프라인이 잡아내지 못하는 유일한 오류다.

#### 판 크기에 대한 판단

포즈 정밀도는 판이 화면에서 차지하는 비율로 결정된다. 190 mm 판을 582 mm에서 보면 0.33이고,
A3 270 mm였다면 0.46이었다. **5×5냐 7×7이냐보다 A4냐 A3냐가 훨씬 큰 지렛대다.**
파일럿에서 평균 재투영 오차가 1 px을 넘으면 격자를 바꾸지 말고 **A3로 판을 키운다.**

### 1.3 화분 배치

판 정중앙. 5 cm 화분이 중앙 4칸에 걸친다. 매 세션 같은 위치(판에 화분 자리 표시).

### 1.4 카메라

카메라 1대. 측면 촬영 후 상면 지그로 이동.

**측면 (8 → 파일럿은 36)**

| 항목 | 값 |
|---|---|
| 판 중심에서 수평거리 | 550 mm |
| 판 평면 기준 높이 | 300 mm |
| 판 평면 대비 올려본 각 | 약 29° |
| 광축 겨냥점 | 판 중심 위 110 mm |
| 회전 간격 | **파일럿 10° (36장)** |

> 측면 카메라를 수평으로 두면 판이 선처럼 눌려 포즈 정밀도가 급락한다. 29° 하향은 필수 조건.

**상면 (5장)**

| 위치 | 판 중심 기준 좌표 (x, y, z) mm |
|---|---|
| T0 (운영용) | (0, 0, 550) — 수직 하향 |
| T1 | (+135, +135, 550) |
| T2 | (−135, +135, 550) |
| T3 | (−135, −135, 550) |
| T4 | (+135, −135, 550) |

모두 식물 중심을 겨냥한다.

> **판이 A4로 작아져도 T1~T4 위치는 ±135 mm를 그대로 유지한다.** 이 좌표는 판 바깥이지만,
> ChArUco가 판을 보기만 하면 카메라 위치를 역산하므로 문제가 없다.
> 판 모서리(±90, ±105)로 좁히면 시차각이 30° → 22.7°로 떨어져 상면 5장의 이득이 줄어든다.

기하 검증: 캐노피 상단 220 mm 가정 시 카메라–잎 거리 330 mm,
**T0 ↔ T1 시차각 30°** — 잎 겹침 해소에 충분.

> **T0만 2뷰 운영용이다.** T1~T4는 레퍼런스(학습 교사) 전용.
> 2뷰 추론은 항상 `T0 + 측면 1장` 조합으로 고정한다.

### 1.5 기준 블록 (스케일 검증)

| 항목 | 값 |
|---|---|
| 물체 | 레고 브릭 등 치수 안정 물체 |
| 높이 | 30~60 mm |
| 실측 | 캘리퍼스로 1회 측정 후 `board_spec.json`에 기록 |
| 위치 | **A1 칸** — 시트 좌표 (13.571, 13.571). 7×7 판은 네 모서리 칸이 전부 검정(마커 없음)이라 **마커를 하나도 가리지 않는다** |

없으면 복원 정확도를 숫자로 낼 방법이 없다. 필수.

### 1.6 컬러차트

프레임 내 판 가장자리에 고정. 기존 홈팜 색보정 모듈 입력.

## 2. 촬영 절차

### 2.0 사전 0회 — 판 인쇄와 검수

인쇄 파일 `build/charuco_board_7x7_190mm_A4.pdf`는 생성 시점에 아래를 자동 검증했다
(`build/charuco_board_7x7_190mm_validation.json`, OpenCV 4.13.0).

| 검증 항목 | 결과 |
|---|---|
| 마커 검출 | 24 / 24 |
| ChArUco 코너 검출 | 36 / 36 |
| 셀 코드 인쇄가 검출에 준 영향 | 코너 이동 0.0000 px |
| PDF 300 dpi 래스터 실측 판 크기 | 190.077 × 190.077 mm (목표 190 × 190) |
| 래스터에서 역산한 칸 크기 | 27.154 mm (목표 27.143) |
| 래스터 PDF 재검출 | 마커 24, 코너 36 |

래스터 실측의 0.077 mm 차이는 픽셀 양자화이지 규격 변경이 아니다.
**`physical_print_verified`는 아직 `false`다** — 실제 종이를 재기 전까지 검증됐다고 기록하지 않는다.

인쇄 후 사람이 확인할 것:

```
[ ] 프린터 설정 '100%' 또는 '실제 크기' — '페이지에 맞춤' 절대 금지
[ ] 여백의 100 mm 자 막대를 자로 재서 100 mm인지 확인
[ ] 판 전체를 재서 190 mm ± 0.5 mm  (칸 하나는 27.142857…이라 자로 검수 불가)
[ ] 검정이 회색으로 나오지 않았는지 육안 확인
[ ] 무광 용지인지 확인 (광택지는 반사로 마커 검출 실패)
[ ] 폼보드/아크릴에 기포·주름 없이 부착 — 1 mm 휘면 그대로 복원 오차
```

자 막대가 100 mm가 아니면 그 비율만큼 **복원된 모든 치수가 틀린다.** 다시 인쇄한다.


### 2.1 사전 1회 — 카메라 내부 파라미터 캘리브레이션

식물 없이 ChArUco 판만 **20장 이상**, 판을 여러 각도·거리·화면 위치로 옮겨가며 촬영.
→ `calib/intrinsics_<camera_id>.json` 생성. **카메라 설정을 바꾸면 다시 해야 한다.**

### 2.2 세션마다

1. 카메라 설정을 **전부 수동 고정**: ISO, 셔터, 초점, 화이트밸런스, 줌.
   자동이면 뷰마다 밝기·초점거리가 달라져 색 분석과 포즈가 동시에 깨진다.
2. 조명 고정. 촬영 중 LED 스케줄이 바뀌지 않는 시간대로.
3. 판 위 화분 자리에 화분, 모서리에 기준 블록, 가장자리에 컬러차트.
4. **측면**: 10°씩 회전 → 36장. **회전 후 5초 대기**(잎 흔들림 정지) 후 셔터.
5. **상면**: 카메라를 상면 지그로 이동 → T0~T4 순서로 5장.
6. 실측·환경 기록 (§3).

세션당 41장.

### 2.3 파일 명명

```
data/raw/<plant_id>/<session_id>/
  images/side_000.jpg ... side_035.jpg
  images/top_T0.jpg ... top_T4.jpg
  session_manifest.json
```

`session_id` = `<plant_id>_<YYYYMMDD>_<HHMM>`

## 3. 기록 체계

사진 외에 아래 3종을 함께 기록한다. 전부 CSV.

### 3.1 `manual_events.csv` — 실제 개화·착과 기록

모델 정답(ground truth)이 되는 기록. 촬영과 같은 날 사람이 눈으로 확인해 적는다.

| 컬럼 | 형식 | 설명 |
|---|---|---|
| plant_id | str | |
| observed_at | ISO8601 | |
| observer | str | |
| event_type | str | `flowering_open` / `flower_bud` / `flower_spent` / `fruit_set` / `fruit_color_break` / `fruit_harvest` / `leaf_removed` / `organ_lost` / `anomaly` |
| truss_index | int | 화방 번호 (아래부터 1) |
| node_index | int | 절위 번호 (자엽절 0) |
| organ_label | str | 사람이 붙인 기관 식별자 (예: `T2-F3`) |
| count | int | 해당 이벤트 개수 |
| note | str | |

> `organ_label`은 사람이 붙인 이름, `organ_id`는 파이프라인이 붙인 이름. **둘은 다른 값이며 섞지 않는다.**
> 연결은 §3.4의 대조표에서만 한다.

### 3.2 `manual_measurements.csv` — 실측 수치

복원 정확도 검증용. 자·캘리퍼스로 측정.

| 컬럼 | 형식 |
|---|---|
| plant_id | str |
| session_id | str |
| measured_at | ISO8601 |
| trait | str — `plant_height` / `stem_diameter_base` / `leaf_count` / `fruit_count` / `truss_count` / `canopy_width` / `reference_block_height` |
| value | float |
| unit | str — `mm` / `count` |
| method | str — `ruler` / `caliper` / `visual_count` |
| observer | str |

`reference_block_height`는 매 세션 기록 — 복원 오차 산출의 기준.

### 3.3 `environment.csv` — 생육환경

| 컬럼 | 형식 | 단위 |
|---|---|---|
| plant_id | str | |
| timestamp | ISO8601 | |
| air_temp | float | °C |
| rh | float | % |
| solution_ec | float | dS/m |
| solution_ph | float | |
| ppfd | float | µmol·m⁻²·s⁻¹ |
| photoperiod | float | h |
| bottom_water_level | str | `full` / `low` / `refilled` |
| source | str | `sensor` / `manual` |
| note | str | |

상시저면이므로 EC·pH는 **저면 양액 기준**으로 기록한다. 측정 지점을 세션 간 바꾸지 말 것.

### 3.4 `organ_label_map.csv` — 사람 라벨 ↔ 파이프라인 ID 대조

| 컬럼 | 형식 |

## 5. 파일럿으로 확정할 것

### 5.1 운영 측면 뷰 수 (미결 D2)

36장에서 **8 / 12 / 18 / 36장 부분집합**을 뽑아 각각 복원하고 비교한다.
추가 촬영 없이 4개 조건을 얻는 설계다.

측정 지표:

| 지표 | 산출 |
|---|---|
| 기준 블록 높이 오차 | 복원값 − 실측값 (mm) |
| 초장 오차 | 복원값 − 자 실측 (mm) |
| hull 부피 | 뷰 수에 따른 수렴 곡선 |
| 엽수 일치율 | 복원 기관 수 ÷ 육안 실측 |

→ 오차 곡선이 꺾이는 지점을 운영 뷰 수로 채택.

### 5.2 측면 판 검출 성공률 (테두리 마커 띠 필요 여부)

측면 36장 중 판 포즈가 풀린 비율을 측정.

- **≥ 95%** → 평면 판만으로 진행, 띠 불필요
- **< 95%** → 회전판 테두리에 ArUco 마커 띠 추가 (외향 부착, 리그 단독 촬영으로 1회 캘리브레이션)

### 5.3 상면 5장의 실효 (가림 해소량)

T0 단독 복원 vs T0~T4 복원의 기관 검출 수 차이.
이득이 없으면 상면을 T0 1장으로 줄인다.

### 5.4 산출물

`pilot_report.csv` — 조건별 지표 + `quality.json` 임계값 제안.
