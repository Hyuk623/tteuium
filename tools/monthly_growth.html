앞으로 30일, 생육 계산

현재 상태에서 시작하는 복엽·줄기 성장 시나리오
사용자 입력 모델 · 정확도 미검증
입력값을 조절해 30일의 변화를 계산합니다. 실측으로 보정된 예측은 아니며, 빈칸을 임의의 작물 값으로 채우지 않습니다. 환경의 영향은 직접 지정한 발달 배율과 환경 반응표로 계산합니다. 품종별 계수는 자동으로 채우지 않습니다.

시작 상태

날짜를 모르면 비워 두세요. 결과는 Day 0~30으로 표시됩니다. 복엽 ID는 이 시나리오 안의 이름이며 실물 식별이 확정되었다는 뜻은 아닙니다.

현재 복엽

성장률과 상한

길이·폭·면적은 ‘현재값 + 성장률 × 발달일’로 증가하여 입력한 상한에서 멈춥니다. 배율 1이면 하루가 1 발달일, 0이면 생장이 멈춥니다. 이 규칙과 계수는 사용자가 설정하는 가정입니다.

면적은 잎 조직의 한쪽 면적입니다. 펼쳐짐이나 그림의 폭으로 면적을 추정하지 않습니다. 고도각은 목표각에 도달하면 멈추고 방위각은 유지합니다.

새 복엽 발생

새 복엽이 처음 나타날 때의 상태

새 복엽은 발생 시점의 줄기 끝에 붙습니다. 기존 복엽의 부착 높이는 유지하는 단순화가 적용됩니다. 소엽 수와 숨은 잎 조직을 자동 생성하지 않습니다.

30일 공통 환경

반응표 모드에서는 사용자가 지정한 각 환경 배율을 곱합니다. 표 범위 밖의 환경값은 계산을 중단합니다.

배율은 필수이며 환경값은 모르면 비워 둘 수 있습니다. 수동 모드에서는 환경값을 바꿔도 생장이 달라지지 않습니다. 반응표 모드는 아래 설정을 사용합니다. 날짜별로 다른 값은 아래 JSON 편집에서 days의 각 행을 수정하세요.
