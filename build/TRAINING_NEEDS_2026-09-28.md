# 딥러닝·GPU 학습이 필요한 항목 (2026-09-28)

원칙(사용자 09-28): **기본(튜닝 전) 모델은 쓰지 않는다.** 사용자가 만든 라벨·검토 결과와, 지금까지 파인튜닝한 모델을 바탕으로 학습한다. 공정한 평가에 쓸 "해당 식물을 뺀" 모델이 없으면, 기본 모델로 대신하지 않고 다시 학습한다.
업로드 분담: 캐글 학습은 Claude, Colab은 Codex.

성능은 모두 **학습에 쓰지 않은 식물로 잰 값**(식물 하나를 빼고 학습, LOPO)입니다.

## 2. 새로 학습해야 할 것 (우선순위 순)

### ① 기관 검출기 v4: 약한 클래스 보강 — **최우선**
- **왜:** 사진만 자동 실행에서 S3 줄기·잎자루 맞춤은 모델이 그린 원줄기·잎자루 윤곽에 의존합니다. 현재 v3 앙상블 성능(식물별):

  | 클래스 | AP50 (dwt_01 / 02 / 03 / 04) | 판단 |
  |---|---|---|
  | 복엽 | 0.76 / 0.79 / 0.92 / 0.93 | 쓸 만함 |
  | 소엽 | 0.68 / 0.69 / 0.69 / 0.69 | 쓸 만함 |
  | 원줄기 | 0.53 / 0.36 / 0.32 / 0.23 | **약함** |
  | 잎자루 | 0.22 / 0.28 / 0.39 / 0.55 | **약함** |
  | 생장점 | 0.09 / 0.11 / 0.08 / 0.03 | **거의 못 잡음** |

  실제로 dwt_01 시점 11 자동 초안에서도 원줄기와 복엽 박스가 나오지 않았습니다.
- **어떻게:**
  - 원줄기·잎자루는 박스보다 **분할(윤곽) 성능**을 봐야 합니다. 지표를 마스크 IoU와 중심선 각도 오차로 바꿉니다.
  - 가늘고 긴 물체라서 줄기 주변을 잘라 확대한 데이터와 클래스 균형 샘플링을 씁니다.
  - 학습 데이터는 사람이 그린 줄기·잎자루 폴리곤입니다(4주 합계 원줄기 55개, 잎자루 135개).
  - 식물 하나씩 빼고 학습(LOPO) + 최종 모델. **빼고 학습한 모델도 모두 저장**합니다.
- **자원:** 캐글 T4, 식물당 약 20–40분 × 5회

### ② 윗면 사진(01·03) 라벨 보강 후 재학습
- **왜:** 윗면 사진에는 사람 라벨이 없어서 모든 모델이 윗면을 본 적이 없습니다.
- **어떻게:** 이미 만든 초안(`build/prelabel_top_20260927`, 7장·박스 190개)을 사람이 고치면, ①과 SAM 학습에 넣습니다.
- **자원:** 사람 검토가 먼저, 그 뒤 캐글 T4

### ③ 잎끝 방향 모델 (S5, 모델 2)
- **왜:** S5가 사람 라벨 대기로 멈춰 있습니다. 규칙은 "잎끝이 카메라 쪽이면 front, 반대쪽이면 back"으로 정해져 있습니다.
- **어떻게:** 4주 회전박스 모델(mAP50 0.81–0.86, 축 오차 9–13°)이 이미 축 방향을 줍니다. 여기에 잎끝 쪽을 가르는 머리(앞/뒤/좌/우)만 추가로 학습합니다.
- **필요:** 사람의 방향 라벨(HUMAN_TASKS 6·8·10·12)

### ④ 사진 간 같은 소엽 짝짓기 순위 모델 (S4)
- **왜:** 생김새만으로 짝짓기는 실패했습니다(SIFT 0쌍, LightGlue 1–2쌍, DINOv2 3/9). 기하만으로는 질문이 많습니다(dwt_02 133개).
- **어떻게:** 사람이 내린 "같음/다름" 결정을 정답으로 삼아, 기하 특징과 모양 특징을 같이 쓰는 순위 모델을 학습합니다. 질문 순서를 정하는 데만 쓰고, 결정은 사람이 합니다.
- **필요:** S4 검토 결정이 쌓여야 합니다(지금은 dwt_01 결정 파일 2개뿐).

### ⑤ 생장점 검출
- **왜:** AP50이 0.03–0.11이라 사실상 쓸 수 없습니다. 라벨도 적습니다(4주 합계 61개).
- **어떻게:** 윗면 사진 라벨이 늘어난 뒤 따로 학습하거나, 복엽의 "전개 중인 잎" 판정으로 대체할지 먼저 결정해야 합니다.

### ⑥ 새 식물이 생길 때마다 이어서 학습
- **흐름:** 사진만 자동 실행(auto) → 사람이 검토·수정 → 수정본을 학습 데이터에 추가 → ①·SAM·회전박스 최종 모델 갱신
- 자동 결과(`review_source='auto'`)는 학습 정답으로 쓰지 않고, **사람이 확인한 것만** 씁니다.

## 3. 학습 없이 추론만 무거운 것 (원격 실행 대상)

| 작업 | 로컬 비용 | 넘길 곳 |
|---|---|---|
| 모델 초안(검출기 3개 × 반전 3방향 + 윤곽) | 식물당 약 35분, 메모리 약 7 GB | 캐글 GPU → 캐글 CPU → Colab CPU(Codex) |
| SAM 소엽 마스크 | 식물당 15–25분 | 위와 같음 |

이 부분은 `tools/offload_job.py`와 `tools/offload_remote.py`로 구현했고, `plant_auto --offload kaggle-gpu`로 씁니다.

## 4. 이번에 고친 학습 관리 문제
- 소엽 검출기가 `patience=30` 조기종료 때문에 1 에폭 모델로 끝나던 문제를 고쳐 다시 학습 중입니다.
- 식물 하나를 뺀 모델을 저장하지 않아 공정한 검증을 못 했습니다(`lopo_dwt_01_s0.pt`는 PC에 0바이트로 남아 있었고, SAM 폴드 가중치는 아예 없었음). 앞으로 모든 학습에서 **식물을 뺀 모델을 전부 저장**합니다.
