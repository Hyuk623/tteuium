# Phase 1 conditional VTC fork: science and IO contract v1

2026-10-11, Codex under the user's explicit one-task exception. Status: conditional implementation contract; independent scientific review and biological acceptance pending. This is a new addendum; historical contracts remain unchanged.

## Audit and selected bounded path

The upstream VTC (`ksmolen2/vtc`, Katarina Smolenova, WUR 2022–2025; adaptation of Jochem Evers' FSPM_BASIC) defaults to FvCB, but consumes gross `output[2]`, clips it, and uses compound-level light. Its leaf/internode dimensions depend on thermal age, not funded growth. Its renew increments climate before consuming prior light. F_CO2=.6 is a biomass-equivalent conversion, not a carbon fraction. These are inherited behaviors, not validation evidence.

The first executable path is a **bounded existing-organ, planar-leaflet fork mode**, named `phase1_leaflet_subset_v1`. It invokes the original VTC `calculatePS_Thornley` function in GroIMP, with native CPU LightModel and a corrected native conservative allocation routine. Original development files are retained separately and are NOT claimed to execute in this mode. No Python growth/allocation solver exists. The full determinate developmental fork and 30-day seed spin-up remain separate acceptance items until implemented and tested. This mode uses the V2 permission for a labelled synthetic initial fixture; it must not impersonate a sowing simulation or whole-plant forecast.

1. NRH consumes **absorbed photons per represented one-sided planar area**, independently for every leaflet. Same response on both optical faces is a labelled scenario assumption; no anatomical-face validation. NRH returns gross exchange (no leaf respiration inside this function). Explicit constant per-area leaf respiration is subtracted over 86400 s once. Non-leaf assimilation and organs outside the declared supported-leaf subset are excluded, never assumed to be modelled. Coefficients require source/cultivar/domain/uncertainty metadata; no fitted Micro-Tom parameters.
2. Internal carbon stock and flux are gC. `gross_umol_CO2 * 12.011e-6` gives gC. Net exchange is gross minus leaf respiration. Additional maintenance = zero explicitly, to avoid double charging. Positive resources fund potential demand proportional to organ demand, capped at demand. Carbon cost = structural DM increment * carbon_fraction / growth_efficiency; growth respiration = allocated * (1-efficiency); reserves receive unused carbon. Deficit: once reserve+net < 0, no growth, final reserve=0 and signed net exchange is retained. The unmet deficit is explicitly reported; such a step is NOT conservation-passing and cannot be published as successful. No concealed import, structural catabolism, clipping loss or reserve reset is allowed.
3. Daily only: export state(k); bind climate(k); compute native light from exactly state(k); photosynthesis/respiration; allocate within plant; update DM; scale blade dimensions by sqrt(new_DM/old_DM) at constant specific leaf area; export state(k+1); derive geometry before next light. Freeze-geometry control updates mass but intentionally fixes optical dimensions and is labelled diagnostic-only. No topology mutation in this mode, no harvest-date overwrite, no automatic light-to-angle response.
4. Optical tissue is individual flat rectangular test blades; each is an explicitly synthetic fixture or supplied rectangular approximation. Area=length*width. No compound envelope, no intercalary correction factor, no hidden tissue. Real measured irregular outlines need another adapter; this path rejects claims of measured optical accuracy. Dimension growth uses a conditional constant-SLA mapping anchored to supplied initial mass and area. This is NOT the original age-logistic geometry law and NOT a validated Micro-Tom mapping.
5. Route A: `synthetic_fixture`, biological age explicitly supplied; no implied 30-day spin-up. Route B: `observation_fixture` or `observation_conditioned`, supported geometry plus explicit assumed hidden mass/reserves and biological age. `fixture` labels never become observations. Missing geometry/scale/mass/age is rejected. Per-field provenance is mandatory. Plant-local Cartesian geometry is a NEW explicit scenario interface, never relabelled board projections. Historical board tools unchanged. Only supplied axes/compounds/leaflets allowed.

## Exact package IO

JSON `request.json`: schema_version=`vtc-python-phase1-1`; run_id, scenario_id; initialization_route; observation_time/start_time/end_time (aware ISO8601); dt_s=86400; intervals positive integer; frame=`plant_local_mm`; geometry_basis=`planar_rectangular_approximation`; topology_scope=`provided_axes`; completeness=`supported_leaf_subset`; biological_validation=`not_established`; nutrient_feedback_enabled=false; evaluation_status=`evaluated_unaccepted`; run_status=`assumption_conditioned`; fixture boolean; model coefficients + evidence; runtime rays/depth/seed/tolerance; source file references. Every source hash frozen at prepare. Source references are package-relative files; ratio pointer target is resolved once and frozen.

Exact CSV schemas (headers also constants in tools/vtc_growth_io.py):

* plants.csv: plant_instance_id,source_plant_id,axis_id,age_days,reserve_gC,tx_mm,ty_mm,tz_mm,yaw_deg,transform_source,mass_source
* leaflets.csv: plant_instance_id,axis_id,compound_id,leaflet_id,parent_id,age_days,x_mm,y_mm,z_mm,length_mm,width_mm,dry_mass_g,potential_dm_g_day,geometry_source,mass_source,age_source
* environment.csv: interval,start_time,end_time,light_hours,temp_day_c,temp_night_c,co2_ppm,source_kind
* light_input.csv: reference_ppfd_umol_m2_s,source_kind,measured_at
* lamps.csv: lamp_id,x_mm,y_mm,z_mm,power_umol_s,source_kind
* light_ratio_latest.txt: one relative path to a ratio CSV. Accept canonical grid table columns grid_row,grid_col,ratio_to_mean (extra provenance columns retained) or slot_id,ratio_now; positive finite, unique keys. It is comparison-only, NOT a second per-leaf multiplier. Ratio normalization population and reference height/frame required metadata; physical height may be unavailable, in which case comparison coordinates are explicit scenario assumptions. Absolute light uses explicit lamp powers. reference PPFD is a declared reference to compare, not a lamp or leaflet multiplier.

Virtual comparison sensors use the canonical 4x4 grid only, with supplied spacing, height and origin. Run separately without plants; compare normalized received flux to ratio_to_mean. Slot-only files cannot identify 16 grid values. Normalized phone ratios are never absolute-light evidence. PPFD=DLI*1e6/(hours*3600) only for constant light. A 14 h scenario gives DLI=PPFD*.0504.

Native tables: `geometry.csv` (state 0..N, IDs, age, canopy coordinates m, dimensions m, area m2, structural DM g); `organs.csv` (interval, IDs, absorbed umol/s, gross umolCO2, respiration gC, net gC, demand gC, allocated gC, growth respiration gC, delta DM g); `ledger.csv` (interval, plant, start reserve, gross/net, leaf respiration, allocation, growth respiration, structural increment gC, end reserve, unmet deficit, residual). Raw native fields retained. Python independently derives normalized gC ledger and geometry hashes, binds time/environment, validates identities, continuity, dimensions, finite values, rates and balances. It performs no biological state update.

Completion JSON is written by GroIMP LAST, with run_id, interval count, input and engine hash tokens and SHA256 of each native CSV. Python additionally requires exit zero, exact output coverage and content hashes. Fresh working directories only, rejected results remain under partial/. Verified publication is a directory rename; no partial success manifest. Replay means a fresh deterministic rerun of complete frozen inputs and seeds, not import of CSV dimensions. Random seed set per interval; verify actual repeat behavior.

## Acceptance limits

Core demonstration requires >=3 intervals, two plants and a stacked-leaf scene; sufficient/limited/dark/frozen controls; independent native and normalized carbon closure; measured engine exit/version; convergence and repeat experiments. Positive net supply with unsaturated demand must cause different mass/area and later lower-leaf light. Darkness depleted case with positive respiration must visibly fail conservation; zero-respiration explicit fixture can show no free growth without failing. No daily-only timestep-refinement claim.

Until the full original-topology adaptation, seed spin-up, arbitrary leaflet outlines and observed Stage-2 mapping are delivered, the overall V2 prompt remains **incomplete**, even if this bounded engine passes. Unknown licensing, science review, actual PPFD/scale/geometry/organ state and independent validation remain open. No `accepted_for_domain` path exists.
