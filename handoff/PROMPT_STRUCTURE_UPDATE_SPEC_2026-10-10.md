## 1. 입력
- 상면 사진, 촬영 시각, 식물 ID(STAGE1 manifest) + 기관 ID와 대응 신뢰도(phynotype2 §7 출력).
- 보정(보드·자·화분 테두리)·측면·깊이 자료는 **실제 파일이 있을 때만** 추가 근거로. 없는 자료를 전제로 한 단계를 만들지 말 것.
- 알려진 조건(사실로 사용 가능):
  - 상면 사진은 손으로 든 휴대폰(원근 투영, 직교 아님) → 화면 가장자리 오차가 커짐.
  - 잎은 하루 주기로 각도가 움직임 → 점등 후 경과 시간이 다른 촬영끼리 각도·투영면적 변화를 생장으로 해석하지 말 것(경과 시간을 상태에 기록).
  - 다른 품종 6개체는 그늘 이웃으로만(식물 단위 MTG), 앉은뱅이 트랙에 붙이지 않음.
  - 보드는 필수 아님(보드 없는 촬영이 기본). 스케일 근거가 둘 이상이면 서로 대조(차이 > 5 % 면 중단·보고).

## 2. 설계할 내용
1. 주줄기·곁가지·마디·복엽·소엽(·소소엽) 연결을 MTG 스케일·연결 규칙(`/` `<` `+`)으로 표현. 기존 ID 보존(재사용·재번호 금지), 날짜별 스냅샷으로 상태 갱신.
2. 값마다 출처 상태 구분: 직접 관측 / 모델 추정 / 생성 후보 / 모름(MTG 상태 어휘 사용). **보이지 않는 줄기·부착점을 사실처럼 만들지 말 것** — 부착 관계를 모르면 '모름' 또는 복수 후보.
3. 면적 3종 구분: ① 보이는 투영면적(px² → 스케일 있을 때만 mm²) ② 가림 보완 추정 투영면적(+불확실성) ③ 실제 잎 표면적(기울기·굴곡 필요). 스케일 없으면 물리 단위로 보고 금지.
4. 상면 단일 영상으로 **기울기·높이·실제 면적이 각각 어디까지 식별되는지** 검토. 결정 안 되는 값은 구간·분포 또는 복수 구조 후보로 남김.
5. 각도 변수 분리 + 기준축 명시: 잎자루 삽입각(줄기 축 기준), 잎(소엽) 표면 기울기(MTG frame 수평면 기준, 부호 + = 위), 소엽 굴곡(잎몸 자체의 휨), 엽축 휨 θ(엽축 기부 방향 기준, 복엽구조 문서). 측정 불가 조건도 함께.
6. 새 관측이 들어올 때 갱신/유지 규칙. **이전 추정값을 새 관측값으로 승격 금지**, 생성 후보를 본 MTG에 섞지 않음(MTG §7).
7. 예측(3단계)에 필요한 구조와 광 계산에 필요한 실제 잎 표면 요구조건을 구분. **복엽 외곽 포락면을 불투명 잎 면적으로 취급 금지** — 광 계산은 소엽 단위 면.
