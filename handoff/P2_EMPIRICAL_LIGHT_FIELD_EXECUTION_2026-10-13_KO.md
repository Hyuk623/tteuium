# 실측 광장 구현 결과 — 2026-10-13

사용자가 확인한 **15cm 위에는 식물이 없음**을 반영했습니다. 조명 조건은 발광부 높이 30cm, 발광 길이 50cm, 등 사이 가장자리 간격 5cm, 하루 14시간, 출력 100%입니다.

## 구현한 기능

- 기존 46개 실측 PPFD를 보간합니다. 각 높이에서 XY 쌍선형 보간을 하고, 7~15cm 사이에서는 높이에 대해 선형 보간합니다.
- 15cm 초과, 7cm 미만, 트레이 밖, 필요한 측정점 범위 밖에서는 광량을 생성하지 않습니다. 일괄 출력에는 해당 위치와 계산 불가 사유를 남깁니다.
- 판·트레이·등 위치·높이·길이·간격·주변 환경의 기록이 바뀌면 구성 해시가 달라져 기존 광장 사용을 거부합니다. 실제로 움직였지만 기록하지 않은 변화까지 감지하는 기능은 아닙니다.
- 입사 방향은 실측하지 않았으므로 확산광 50·60·70%를 각각 가정한 결과로 출력합니다. 기존 잎 통과 횟수 계산을 재사용하고 벽 반사율을 맞추는 계산은 하지 않습니다.
- 잎별 광량은 면적을 곱한 광자량을 먼저 합산한 뒤 지원 면적으로 나눕니다. 시나리오별 값과 차이를 별도로 출력합니다. 잎 투과율이 미상인 경로는 미확인 상태로 남깁니다.
- 기존 `reference_dli`에 새 실측 광장 경로를 추가했습니다. `PPFD × 14 × 3600 / 1,000,000`으로 점등 시간 동안의 일일 광량을 계산하며, 모든 값은 `empirical_light_field / derived`로 표시합니다. 기존 측정·시뮬레이션 결과 형식의 의미는 유지했습니다.

## 결과와 검증

새 결과 폴더: `build/p2_empirical_light_field_20261013_01/`.

- 실제 46점 자료로 네 가지 좌표 방향 가정별 패키지를 만들었습니다. 어느 방향이 사실인지 계산 오차로 선택하지 않았습니다.
- 각 패키지는 19개 위치 중 17개를 조건부 계산하고, 범위 밖 2개를 거부했습니다. 네 패키지 모두 독립 소비자 검증을 통과했습니다.
- 합성 잎 2개와 가림 잎을 사용해 3개 방향 가정별 계산·차이 출력을 확인했습니다. 실제 식물의 잎별 예측 결과는 아닙니다.
- **총 254개 테스트 통과**, 이 중 신규 기능 테스트 29개입니다. 패키지 실행 점검 19개도 통과했습니다.
- 소비자 산술 허용오차는 절대·상대 각각 `1e-12`입니다. 잎가림 비교는 절대 `1e-10`, 상대 `1e-12`; 확산광 각도 분할 수렴 확인은 절대 `0.01`, 상대 `0.001`입니다.

예를 들어 현재 기록된 좌표 방향 가정에서 `(280, 210, 110) mm`는 PPFD 약 **249.25 µmol/m²/s**, 14시간 점등 광량 약 **12.56 mol/m²/day**입니다. 해당 위치에서 직접 측정한 값은 아니며, 실제 점등 중 광량이 일정하다는 조건부 파생값입니다. 소등 시간의 주변광과 실제 점등 시작·종료 시각은 미확인입니다.

## 남은 조건

코드 경로는 구현했지만 **실제 식물의 잎별 수광량과 실물 정확도는 아직 미검증**입니다. 현재 기록에는 검토된 잎 표면, 등 위치·방향, 측정 격자의 정확한 원점·방향, 측정기 보정자료가 부족합니다. 실제 자료용 패키지에서는 등 방향을 임의로 채우지 않았고, 합성 형상 검증을 별도 패키지로 분리했습니다.

15cm 측정면 위에 잎이 없다는 조건은 반영했지만, 측정 당시 아래에는 식물이 있었다는 기록은 유지합니다. 각도별 광 분포와 생리·성장량을 실측한 것으로 간주하지 않습니다. P3 성장 예측이나 다른 프로젝트 연결은 실행하지 않았습니다.

등을 옮겼을 때의 광량은 이 방식으로 예측하지 않으며 **새 배치에서 재측정**해야 합니다. 이 비용은 미결 작업이 아닌 사용자 결정의 수용된 결과로 기록했습니다.
