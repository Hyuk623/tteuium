# P2 조명 보정 코드 작업 결과 — 2026-10-13

**보정·출력·DLI 연결 코드를 구현하고 합성 장면으로 검증했습니다. 실제 선반 보정은 입력 부족으로 미완료입니다.**

이번 대화에서 확정한 조건은 **판 위 30cm, 하루 14시간, 출력 100%, 램프 사이 5cm 간격**입니다.
기존 기록은 바꾸지 않고 새 build 패키지의 운영 조건으로 보존했습니다.

## 구현한 내용

- 기존 방향성 막대광원·반사면·센서를 사용한 Native 보정 경로.
- 보정 자료와 검증 자료 분리, 입력·코드 해시 동결, 광선 수·실행 횟수 제한.
- 전체 반사 장면, 같은 위치의 검은 벽, 벽을 제거한 장면 비교.
- 기존 직접광 계산과 Native 결과의 독립 비교.
- 위치별 보정 예측값 → DLI 출력 → 독립 소비자 검증 연결.
- 좌표·시간·해시가 맞지 않거나 근거가 부족하면 사용 불가로 유지.

성장 모델, 사람의 설정·측정 원본은 변경하지 않았습니다.

## 확인 결과

- 관련 P2·DLI·통합 테스트 **225개 통과**.
- 합성 관측 생성 4회와 보정·대조군 **42회 Native 실행**.
- 최종 비교는 **480만 광선**, 서로 다른 시드 2개 사용.
- Native 원시 광량과 출력값의 일치, 기존 직접광 대조군 검증 통과.
- 내보낸 예측값을 DLI로 적분하고 독립 소비자가 재계산하는 경로 통과.

합성 시험의 보정 반사율은 **탐색 상한 0.8**에 닿았습니다. 합성 정답 0.4를 회복하지 못했으므로,
프로그램 실행이 확인됐다는 뜻이며 반사율 추정 정확도가 입증됐다는 뜻은 아닙니다.
경계 도달과 미확인 불확실성을 결과에 그대로 남겼습니다.

격자 시작 모서리·방향과 당시 식물 형상도 완전히 확정되지 않았습니다.
