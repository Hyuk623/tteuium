## Implemented and generated

- `tools/manual_leaf_preview.py` and `.html`: standalone diagnostic landmark triangulation and partial surface display. The original point/pose gates remain recorded; experimental finite estimates are retained with failed flags. No operational configuration or core code was changed.
- `tools/tests/test_manual_leaf_preview.py`: three tests pass for exact point recovery without promoting failed camera quality, visible failed point residuals without changing thresholds, and rejection of absent poses/duplicate views/out-of-frame pixels.
- `build/photos1_manual3d_20260919/capture.preview.json`: all 18 input frames; 17 raw ChArUco poses; zero accepted by the existing 1 px camera-pose gate. Uses the already-existing board-only trial intrinsics, without recalibrating or promoting them.
- `build/photos1_manual3d_20260919/manual_candidates.json`: assistant-proposed corresponding boundary landmarks for six candidate leaflets on six photographs. The preview labeling coordinates are explicitly scaled from 1500 x 1500 to 3024 x 3024. All identities/boundaries are unreviewed candidates, not human ground truth.
- `build/photos1_manual3d_20260919/preview03/index.html`: offline, self-contained rotatable partial model and 18-photo review gallery. Six photographs have manually proposed labels; other solved views show **projected candidates**, not manually confirmed labels. IMG_7910 has no pose and no projected labels.
- The same folder contains estimated-mm PLY, point/contour candidate CSVs, point-fit diagnostics, full annotated JPEGs and enlarged annotation JPEGs. The outputs deliberately do not use the operational `leaf_surfaces.csv` filename or claim PPFD suitability.

The model contains six coarse leaflet patches (38 boundary points, 26 triangles), **not a reconstructed whole plant**. Leaf-level maximum correspondence residuals range from 15.6 to 43.6 original-image pixels. Most triangles do not pass the existing contour-support tolerance; the viewer marks these with orange edges. Labels and camera error can both contribute; no accuracy claim is supported.

Browser checks: opening the page, switching the leaf ID and linked source photos, and side-by-side model/annotation display were inspected. Computation tests passed; the complete plant is unfinished. The page retains all failures rather than reporting the whole goal as complete.

## Reproduce

```powershell
python -m tools.manual_leaf_preview --capture build/photos1_manual3d_20260919/capture.preview.json --annotations build/photos1_manual3d_20260919/manual_candidates.json --out build/photos1_manual3d_20260919/another_preview
python -m pytest -q tools/tests/test_manual_leaf_preview.py
```

Use a new output directory on each run. Raw poses can be regenerated by `build/photos1_manual3d_20260919/inspect_correspondence.py`; it imports the sole core board-to-camera conversion. No nominal-angle or SfM pose is used.
